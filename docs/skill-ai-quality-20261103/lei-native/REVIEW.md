# 神话再临·雷：开发审查（待验证）

清单按 1.11.7 `character/shenhua.js` 的八名武将及 `character/tw.js` 的踞襄核对，共16项登记技能。下面的“保留”指本轮不追加未经证明的策略；不代表原AI最优。扩展 `shenhuaLei` 通过 `skillAIPolicyPacks.js` 注册、`policyCore` 安装和卸载。宿主 `noname/library/element/content.js` 消费触发技 `check`；选择事件消费 `ai`/`ai1`/`ai2`/`processAI`，`noname/get/index.js` 的 effect 消费 `ai.effect.target`。完整引擎有自身出牌决策，不能据此假定所有原生评分都被其消费。

## 接线与风险

- 原生累计补丁：箜声、镇骨、父荫、谦节共4技能、4名武将；箜声是既有扩展修复同步，不计成本轮新增质量优化。
- 扩展：箜声、父荫、谦节；镇骨回调嵌于 cost，不重写技能结算，仅原生候选。父荫和谦节通过 host.wrap 接入宿主 effect；宿主 get.effect 确有消费入口，完整引擎出牌路径不保证使用它，不能宣称所有模式一致。
- 被动谦节通过铁索关联评分修改；父荫通过伤害牌目标 effect 修改。庸肆、破势为强制规则，未增加独立虚构入口。
- 代码完成、待验证：所有候选未做真实宿主、多人联机、AI托管、回归或效果收益验证。`countCards` 的雄乱权重不足、罪论排序及嵌套事件安全接线均为保留限制。候选可能影响策略质量，应通过后续场景验证。
