# 界风第五轮候选验收：互斥降级，待验证

界限突破·风与神话再临·风目前**不支持同时安装或启用**。共享策略核心在任何分包包装前拒绝同时启用或第二个独立宿主启用；若卸载时有外部包装阻止确认恢复，则保留互斥标记至重启。安装器在预检阶段拒绝发现另一包的注册导入。拒绝后不应留下本次包装或文件修改。

本候选更新了共享 policyCore.js，旧版共享核心与本包SHA不同；安装器会拒绝覆盖已存在的不同版本核心，不能直接安装在旧神话风或使用旧核心的其他分包之上。不要手工覆盖有用户改动的共享文件。切换前先退出宿主，按已安装包的 rollback-pack 卸载，完成文件操作后重新启动宿主；若需使用冻结神话风旧包，且已确认没有其他包依赖新核心且不存在用户改动，再使用冻结包内原版 policyCore.js 恢复旧共享核心，然后安装神话风并重启。若有其他分包，先核对其共享依赖和安装记录；不能安全确认时保留现状。旧神话风ZIP未修改，单独使用保持原有评分：当前夹具杀次数0/1均为17；这不是共存修复。
