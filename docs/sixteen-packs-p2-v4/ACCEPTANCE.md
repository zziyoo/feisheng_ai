### 2.1 雄乱补充

- v4 包装器只在宿主原目标回调指纹吻合时接管；一杀对 1HP 八卦敌人分数为 0，两杀为正，无合法后续攻击/无护甲的正例按规则区分。
- 实际自动选择六场没有选择友方目标；两杀场景目标为敌方并写入 `drlt_xiongluan_ban`。
- `ai.effect` 使用者方向哨兵为 `zeroplayer`，卸载后恢复；共享引擎的泛用静态画像仍可能标成支援，保留为残余 P2，不冒充本轮已解决。

### 2.2 强袭补充

- 正例要求使用者至少 4HP、唯一装备为原版诸葛连弩、目标合法且无可见防御/响应、至少两次有效额外杀、收益高于失去体力估值。
- 距离 2、低血、后续攻击不足、非连弩武器、无有效目标等反例不会被保护规则套用；对应确定性测试通过。
- 后置测试 `v4-qiangxix-poststate`：距离 1、`canUse=[true,true]`，实际用两张杀，连弩保留。
- 火包历史原生备选补丁没有同步本项扩展优化，原生路线仍为旧行为。

### 2.3 罪论补充

- 真实宿主公开流程已覆盖：有/无公开判定、不同可获得张数、不同暗手牌；实际 `chooseToMove` 返回合法分区，输入展示牌未被 wrappers 改写，卸载后事件回调恢复。
- v4 只读三张展示牌、下一角色公开判定区、态度、静态牌值；乐/兵粮/闪电使用宿主固定判定语义；动态牌值/未知判定按 0 处理。
- 限制：v3 在该固定公开局面与 v4 产生相同移动结果，因此“隐藏信息差异”不是由真实宿主 fixture 复现，而是由 `tools/test-shenhua-lei-zuilun.mjs` 的隐藏 getter/静态路径测试覆盖；不把它宣称为真实宿主已复现的 v3 缺陷。

### 2.4 踞襄补充

- v4 正例：群势力一血、空手、唯一八卦、敌方在攻击范围；友方主公至少 3HP、空防具栏；AI 选择不使用技能，八卦保留。
- v3 同局面：AI 使用技能，八卦进入主公装备区，己方装备区清空。
- 反例：主公 1HP 时仍赠送；武器 `zhangba` 仍赠送；复栏/无威胁/其他装备按原逻辑保留。
- 本项没有 v4 原生对应实现，正式路线仅扩展。

### 2.5 界奇谋补充

- v4 场景：己方 4HP、丈八蛇矛、2 张杀，敌方 2HP、+1 马使距离 5；真实宿主 `playerResult=1`，支付 2、摸 2、连续两杀击杀；v3 同局面 `playerResult=0`，不发动。
