# AI技能优化初步测试包

这份材料用于安排本体武将AI的初步测试，范围是标准包、风火林山阴雷，以及界限突破中的对应武将，共142个版本。

包里是方案和测试清单，没有可安装的AI代码。现有拓展没有改动。

## 先看哪份

- 《AI技能优化初步测试清单.md》：按武将列出技能、准备检查的地方和重点测试场景。
- 《详细方案-标准界限突破风火林山阴雷.md》：查看整体改法和测试要求。
- 《测试任务清单.json》：方便按武将分配任务，目前不是可以直接运行的测试脚本。
- 《决策日志模板.json》：记录测试结果，里面的空值需要实际测试后填写。
- 《GitHub源码清单.json》：核对本次参考的源码版本。

## 怎么测

先测56个优先检查的版本；另外75个根据实测结果决定是否修改，11个暂时保留。这个分类是安排检查顺序，不代表已经确认有问题。

每项尽量保留相同的阵容、座次和起始局面，对比原AI与修改后的AI。记录它选了什么、实际做了什么、结算结果和耗时。遇到异常请保留录像、日志和复现步骤。

测试时请写清游戏版本、武将ID、模式及启用的拓展。同名武将可能有不同版本，以清单中的ID为准。不要只用胜率判断改动好坏，也要看是否出现乱交保命牌、无收益发动、误伤队友等具体问题。
