# 无名 AI 十六包 v3 整改候选

本目录对应无名杀 1.11.7 Windows x64。正式组合仍为十份原生 AI 补丁加六份扩展 ZIP，共 143 条武将登记和 281 条武将技能关联。历史稳定版保存在桌面 `feisheng-ai-sixteen-packs-final`。

- [验收状态](ACCEPTANCE.md)列出新执行、按字节继承及未覆盖的检查。
- [P2 整改台账](P2-RESOLUTION.md)逐条记录原 25 项工作清单的处置与证据。
- [十六包台账](TENCENT-PACK-PLAN.csv)列出每包武将数、技能关联、源码审查、部署、验收及遗留事项。
- [变更记录](CHANGELOG.md)、[产物来源](PROVENANCE.md)及 [校验清单](SHA256SUMS.txt)用于核对源码、构建、证据和文件。
- [部署](DEPLOYMENT.md)、[升级和恢复](UPGRADE.md)、[支持与互斥矩阵](COMPATIBILITY.md)说明适用范围。
- [腾讯表格同步记录](TENCENT-SYNC.md)与 [待粘贴增量](TENCENT-UPDATE.csv)记录在线同步状态。

以同版外层验收状态为准。归档内的旧版验收元数据以原字节保留。外部集成回执仍为 pending，公开发布状态为未发布。
