# 从历史稳定版升级及回滚

1. 先读 [验收状态](ACCEPTANCE.md)。标为 PARTIAL 或 BLOCKED 的目录仅用于隔离验证。已部署环境保留历史稳定版，直到补齐对应门禁。
2. 完全退出宿主。保存安装目录五个宿主文件、扩展根、`.djsc-pack-backups/` 和各旧版解压目录。按 [来源](PROVENANCE.md) 确认当前部署版本和各自哈希。安装器不能自动识别所有原生补丁。
3. 如需做隔离升级，使用各旧 ZIP 自己的回滚器按扩展逆序回滚，使用旧补丁按原生逆序撤销。核对宿主五文件恢复到干净 1.11.7 LF 字节，并确认扩展根已恢复到兼容状态。存在旧核心或第三方文件冲突时，先保留文件及日志，再从干净 `1fe5292` 扩展副本按部署说明恢复。安装器没有自动合并或迁移第三方核心的功能。
4. 按 [部署说明](DEPLOYMENT.md) 重新应用十份补丁和安装六份 ZIP。检查注册表六条唯一导入、共享文件哈希及各包清单。每个包安装前运行 `--dry-run`。
5. 回退时先用 v3 各包自己的回滚器逆序回滚扩展，再用 v3 补丁逆序撤销。核对字节后，再从已保留的旧目录恢复旧稳定组合。

哈希错误、CRLF、部分回滚或第三方冲突时停止后续步骤。保留日志，用同版本备份恢复已确认的文件。若缺少旧安装器或原始补丁，使用干净宿主和完整扩展副本重新布置。历史六包原生备选路线须单独部署。
